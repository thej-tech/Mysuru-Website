# 🌸 Mysuru — The City of Royal Heritage

A simple multi-page website showcasing the **history, culture, tourist attractions, and hospitality of Mysuru**.

The project was created using **HTML and CSS** with a focus on semantic HTML, simple responsive design, accessibility, and clean navigation.

---

## 🌆 About the Project

Mysuru, formerly known as Mysore, is one of Karnataka's most culturally significant cities.

This website presents different aspects of Mysuru, including:

- 👑 Royal heritage and history
- 🏛️ Famous tourist attractions
- 🎭 Culture and traditions
- 🍬 Famous Mysuru food and products
- 🏨 Hotels and accommodation
- 📝 Visitor feedback

The website is designed as a small multi-page informational website rather than a single-page layout.

---

## 📄 Website Pages

| Page | Description |
|------|-------------|
| 🏠 **Home** | Introduction to Mysuru and highlights of the city |
| 👑 **Legacy** | History and royal heritage of Mysuru |
| 📍 **Places** | Popular tourist attractions |
| 🎭 **Culture** | Festivals, traditions, food, art and local culture |
| 🏨 **Hotels** | Information about hotels and accommodation |
| 📝 **Feedback** | Form for visitors to share their experience |

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- Semantic HTML elements
- Forms and input elements
- CSS Flexbox/Grid
- Responsive design
- Basic accessibility practices

No frameworks or external libraries were used.
